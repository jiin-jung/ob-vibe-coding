# 자료 조사

담당 팀원이 바로 수정하는 문서다. 아래 표에 한 줄씩 추가한다.

- **상태:** 초안 / 확인 완료
- **출처:** 링크를 꼭 적는다. 없으면 "추정"이라고 적고 계산식을 쓴다.
- **발표:** 발표에 쓸 내용이면 "O"로 표시한다.

"초안"은 Codex가 조사했고 팀에서 아직 확인하지 않은 내용이다.
