## 2. 공통 규정의 적용 범위 (혼합 금지)

- **학교 공통 + 학번 구분 없는 게시본**: 수강학점, 성적 비율, 학사경고·제적, 휴학 종류, 조기졸업, 부·복수전공
  - 페이지 수정일은 2023~2026년으로 제각각임. "2026학번 전용 규정"이라는 표기는 없고 **현재 게시본**일 뿐임
- **학번에 따라 다름**
  - 졸업학점 130: 2023학번↑
  - 첫 2학기 휴학 제한: 2023학번↑
  - AI 기초교양: 2026학번↑
  - 교양 30~55학점: 2012학번↑ (문면상 2026 포함 → conditional)
- **학과·계열에 따라 다름**
  - 전공학점(72/63/60과 예외 학과)
  - 대학수학 이수 대상(자연·공학계열)
  - AI사고와데이터리터러시 이수 대상(해당학과)
  - 영어인증 상향 학과
  - 수강 금지 과목
  - → 학과 원문이 필요하고, 학교 공통 130학점과 섞어서 쓰면 안 됨
- **학기·공고에 따라 다름**
  - 교환 일정·지원금·잔여학점 조건: 2027-1 파견 공고에 한정
  - 2028 파견에 그대로 가져다 쓰면 안 됨
- **조문 원문**
  - 학사안내가 인용한 학칙 제23·42·50·51조, 시행세칙 제11·21·23·60조가 있음
  - rule.inu.ac.kr 규정 검색은 JS로 로딩되어 내려받을 수 없었음(8037 학칙 등·8050 검색·lawSearchView 2회 시도)
  - → 조문 본문과 개정일은 미확인

## 4. 게임 사용 원칙

- JSON의 `fact`는 원문 사실만 담음. 게임 스탯·점수는 별도 필드로 둠
- 교환 300점은 선발 절차 설명일 뿐이고 게임 점수가 아님
- conditional 항목은 화면에 "최신 공고/학과 확인" 문구를 함께 표시
- 동아리는 49개 목록을 하드코딩하지 말고 분과 단위와 공식 링크로 처리
