# 심사 기준

출처: 대회 심사 안내 슬라이드. 주제는 `TOPIC.md`, 규칙은 `RULES.md` 참고.

## 심사위원

정보기술대학 소속 교수진 3인, 정보기술대학 학생회

## 평가 항목 (50점 만점)

| 항목 | 배점 | 슬라이드 원문 |
| --- | --- | --- |
| 창의력 | 20점 | 아이디어의 참신성 및 학교 문제 해결성 |
| AI 활용 능력 | 15점 | AI 툴 활용도 및 프롬프트 로그 우수성 |
| 결과물 완성도 | 15점 | 서비스 작동 여부 및 시연 명확성 |

## 우대 가산점

자유전공학부 진입생 또는 편입생 포함 팀 +5점

## 의사결정 체크

기능이나 기획을 결정할 때마다 아래를 묻는다. 어느 항목의 점수도 올리지 못하면 대회 범위에서 뺀다.

1. **참신성:** 캠퍼스팅, 캠밋, 에브리타임에 없는 점을 심사위원에게 한 문장으로 말할 수 있는가?
2. **학교 문제:** 인천대 학생의 실제 문제를 푸는가?
3. **AI 활용:** 서비스와 개발 과정에서 AI가 실제 역할을 하고, 프롬프트 로그로 보여줄 수 있는가?
4. **작동:** 시연에서 목업이 아니라 실제로 동작하는가?
5. **시연:** 3분 시연 흐름 안에서 보여줄 수 있는가?

## 현재 기획 적합도

점수가 아니라 재수강 기획 기준 판단이다.

| 항목 | 상태 | 근거 | 해야 할 일 |
| --- | --- | --- | --- |
| 창의력: 참신성 | 중간~높음 | 후회 맞춤과 현실 퀘스트 분기가 차별점. 레퍼런스의 공개 자료에서는 AI와 현실 연동이 확인되지 않음 | 게임 재미를 실제 프롬프트로 확인 |
| 창의력: 학교 문제 | 중간 | 게임이 실제 행동으로 이어지지만 효과 근거는 없음 | 후회 설문, 발표에서 단순 게임이 아님을 설명 |
| AI 활용: 서비스 | 설계 완료 | 목표, 이벤트, 사진 판정, 엔딩에 AI 사용 | 실제 프롬프트 작성 |
| AI 활용: 프롬프트 로그 | 진행 중 | 평가 대상인데 제출 형식 미확인 | 운영진 확인, 로그 보관 |
| 완성도 | 미착수 | 재수강 코드 없음 | 사용자가 빌드 시작을 결정한 뒤 진행 |
| 가산점 | 해당 없음 | 팀에 자유전공학부 진입생이나 편입생이 없음 | 없음 |
