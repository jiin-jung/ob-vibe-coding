# 인천대 사실 자료

게임에 쓰는 인천대 정보의 근거다. 2026-11-06에 검색한 결과이며, 이 표에 있는 내용만 실제 정보처럼 사용한다.

- **공식 확인:** 학교 공식 페이지 원문을 직접 읽음
- **공식 요약:** 학교 페이지가 출처지만 검색 요약으로만 확인함. 원문 확인 필요
- **외부 자료:** 학교 신문, 기사, 나무위키 등. 현재와 다를 수 있음
- **재학생 확인:** 팀원이 직접 확인함

## 재학생이 채울 것

- 게임에 넣을 학과 특징
- 인천대생만 웃을 수 있는 소재: 통학, 시험 기간, 학식 메뉴, 수강신청, 축제
- 위 표의 "미확인"과 "재학생 확인 필요"
- 실존 교수와 학생은 소재로 쓰지 않는다
