# 화면 구성

## 방향

킥루처럼 모바일 앱에 가까운 화면을 쓴다. 연한 회색 배경, 흰색 둥근 카드, 화면 아래 고정된 큰 버튼, 단계별 입력, 도트 캐릭터와 진행 단계 표시, 첫 화면의 오늘의 랭킹이 참고할 구조다.

이름, 문구, 그림, 색 조합은 가져오지 않는다. 재수강의 고유성은 학사 포털과 성적표, 통지문, 직인에서 나온다.

- 색: 학사 포털을 닮은 남색, 성적과 경고용 빨간 직인
- 캐릭터: 직접 만든 도트 학생 남, 여 각 1종. 표정만 상태에 따라 바뀜. 게임 수치에는 영향 없음
- 글자: 통지문은 공문 느낌, 숫자는 성적표 느낌

## 첫 화면

```text
재수강                        [랭킹]
┌────────────────────────────┐
│      [도트 학생 캐릭터]      │
│   귀하는 재수강 대상입니다   │
│  1학년─2학년─3학년─4학년─졸업 │
└────────────────────────────┘
┌ 오늘의 랭킹 ─────── 전체 보기 ┐
│ 1 닉네임  컴공   전설 3  240점 │
│ 2 닉네임  시스템 전설 2  210점 │
│ 학과 대항전: 컴공 1위         │
└────────────────────────────┘
[ 재수강 신청하기 ]             (고정)
```

## 시작: 3단계

```text
← ● ○ ○
어느 학과로 복귀할까요?
[컴퓨터공학부]
[인공지능정보통신공학부]
[인공지능시스템공학과]
[ 다음 ]
```

2단계는 닉네임, 캐릭터(남, 여)와 선택 로그인, 3단계는 후회 입력이다. 이어서 "복귀 처리 통지서"에 회귀 목표를 보여준다.

## 학년 계획

```text
2학년  ■■□□  이수 34/130  평점 3.4
학업 ▓▓▓░ 인맥 ▓▓░░ 멘탈 ▓░░░ 낭만 ▓▓░░
잔액 120만 원
┌ 등록금 200만 원  [납부] [대출]  ┐
┌ 수강  [34] [38] [42 잠김]       ┐
┌ 재수강  자료구조 C0  [신청]     ┐
┌ 활동  [근로][알바][드림이][동아리]┐
┌ 상점  에너지 음료 10만 원 [구매] ┐
[ 이번 학년 시작 ]
```

## 이벤트

```text
2학년  ■■□□
┌ [통지] 조별 과제 조 편성 결과 ───┐
│ 귀하의 조원 3인 중 2인이          │
│ 연락 두절 상태입니다.             │
│ 나머지 1인은 귀하입니다.          │
└────────────────────────────┘
[ 혼자 다 한다      학업+ 멘탈- ]
[ 교수님께 메일을   평판+ 인맥- ]
```

고르면 통지문이 처리 결과로 바뀌고 스탯이 움직인다.

## 현실 퀘스트

```text
┌ [현실 이수 과제] ──────────┐
│ 다른 과 건물 입구를 찍어      │
│ 제출하십시오.                │
│ 얼굴이 나오지 않게 찍어 주세요 │
└────────────────────────────┘
[ ] 얼굴이 나오지 않았습니다
[ 사진 찍기 ]
[ 나중에 인증 ]
```

판정 중에는 "학사 시스템이 심사 중입니다"를 보여주고, 통과하면 빨간 "이수" 직인이 찍힌다.

## 결과: 재수강 성적표

가장 공들일 화면이다. 그대로 저장해서 공유하기 좋게 만든다.

```text
┌ 재수강 성적표 (가상) ──────┐
│ 닉네임  컴퓨터공학부  3회차   │
│ 이수 132  평점 3.8           │
│ 학업 A0 인맥 B+ 멘탈 C0 낭만 A+│
│ 칭호  조원을 구한 자          │
│ 엔딩  대기업 취업     [졸업]  │
│ 업적  전설 1 · 고급 2         │
│ 현실 이수 완료       [이수]   │
└────────────────────────────┘
현실에서 해볼 다음 행동: ...
[ 저장 ] [ 공유 ] [ 다시 재수강 ]
[ 랭킹 등록 ]
```

## 랭킹

탭 3개: 종합, 학과 대항전, 업적별. 10초마다 갱신한다.
