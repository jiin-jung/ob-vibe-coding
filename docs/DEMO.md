## 프롬프트 로그

제출 형식은 운영진에게 확인한다. 정해진 형식이 없으면 아래 방식으로 낸다.

- 전체 대화 원본은 보관하고, 선별한 5건을 `PROMPT_LOG.md`에 정리한다.
- 개인정보와 키는 지운다. 나중에 지어낸 로그는 넣지 않는다.

| 항목 | 내용 |
| --- | --- |
| 시각, 도구 | 언제, 어떤 AI를 썼는지 |
| 목적 | 무엇을 하려 했는지 |
| 프롬프트 | 원문 |
| 결과 | 응답 요약 |
| 판단 | 무엇을 채택하거나 거절했는지와 이유 |
| 연결 | 관련 기능이나 파일 |

## 서비스 내 AI 프롬프트

| 기능 | 입력 | 출력 |
| --- | --- | --- |
| 조합 이유 | 학과, 관심사, 분위기 | 공통점과 이유 2~3문장 |
| 활동 카드 | 단계 수, 학과, 관심사, 분위기, 불편한 주제, 후보 목록 | 단계별 활동과 미션, 주도자 멘트 |
| 사진 판정 | 미션 설명, 사진 | 통과 여부, 이유 한 문장 |
| 추억 카드 | 완료한 미션과 관심사 | 한 줄 후기 |

- 사용자 입력은 지시가 아니라 데이터로 다룬다.
- 활동과 미션은 코드에 둔 안전한 후보 목록에서만 고른다. AI는 고르고 멘트만 쓴다.
- 짝 게임 질문처럼 새로 쓰는 문장은 금지 주제를 코드로 한 번 더 거른다.
- 호출마다 `ai_logs`에 프롬프트 버전, 입력, 출력, 실패 여부를 저장한다. 이름과 메일은 넣지 않는다.
