# Userflow

## 전체 흐름

```text
닉네임과 학과 입력 → 후회 입력 → AI 회귀 목표 → 1학년 이벤트와 선택 → 2학년 이벤트와 선택
→ 현실 퀘스트(인증 또는 나중에) → 3학년 이벤트와 선택(인증 시 숨겨진 선택지) → 4학년 이벤트와 선택
→ 성적표, 칭호, 엔딩, 가상 졸업장 → 공유, 다시 하기, 랭킹 등록(메일 인증)
```

## 1. 시작

1. 닉네임과 학과를 입력한다. 로그인 없이 시작하거나, `@inu.ac.kr` 메일로 먼저 로그인할 수 있다. 로그인하면 기록이 쌓인다.
2. "대학생활에서 가장 후회되는 것"을 입력하거나 예시를 고른다.
3. AI가 목표 유형을 정하고 회귀 목표를 문장으로 보여준다.

| 예외 | 처리 |
| --- | --- |
| 후회 입력이 비어 있음 | 예시를 고르게 함 |
| 심각한 내용 | 상담 안내를 먼저 보여주고, 원하면 일반 목표로 계속 |
| AI 실패나 지연 | 샘플 목표로 진행하고 샘플이라고 표시 |

## 2. 학년 진행

1. 등록금을 낸다. 돈이 모자라면 대출을 받거나, 한도를 넘으면 휴학한다.
   수강 학점, 재수강, 활동을 고르고 상점에서 아이템을 산다.
2. AI가 쓴 이벤트 장면과 선택지 2개를 보여준다.
3. 고르면 코드가 스탯과 성적, 이수 학점을 계산하고, 결과를 짧은 장면으로 보여준다.
4. 다음 학년으로 넘어간다. 4학년이 끝날 때 130학점이나 영어졸업인증을 못 채우면 초과 학기 엔딩으로 간다.

선택지의 스탯 변화는 코드에 정해둔 유형에서만 고른다. AI가 숫자를 정하지 않는다.

## 3. 현실 퀘스트

1. 2학년이 끝나면 목표에 맞는 퀘스트가 뜬다.
2. 얼굴이 나오지 않음을 확인하고 사진을 올린다.
3. 서버가 위치 정보를 지우고 AI가 판정한다.

| 결과 | 처리 |
| --- | --- |
| 통과 | 3학년 숨겨진 선택지가 열리고 사진을 저장 |
| 실패 | 이유를 보여주고 다시 찍기. 사진은 버림 |
| 얼굴이 뚜렷함 | 다시 찍게 함 |
| AI 판정 실패 | 다시 시도 또는 나중에 인증 |
| 나중에 인증 | 숨겨진 선택지 없이 진행. 결과 화면에서 인증하면 추가 엔딩이 열림 |

## 4. 결과

- 코드가 점수와 성적을 계산한다. AI는 칭호 후보 중 하나를 고르고 엔딩을 쓴다.
- 성적표와 가상 졸업장을 이미지로 저장하거나 공유한다. 공유 화면에 후회 원문은 넣지 않는다.
- 끝에는 현실에서 해볼 다음 행동 하나를 보여준다.
- 다시 하기를 누르면 "재수강 N회차"로 새로 시작한다.

## 5. 랭킹

1. 비로그인 플레이의 랭킹 등록을 누르면 `@inu.ac.kr` 메일을 입력한다. 로그인 플레이는 자동으로 누적한다. 다른 도메인은 프론트와 서버에서 모두 거부한다.
2. 메일로 받은 6자리 코드를 입력한다. 코드는 10분 뒤 만료되고, 입력은 5회, 재전송은 60초 간격으로 제한한다.
3. 닉네임과 학과, 업적, 명예 점수만 공개한다. 후회 원문은 공개하지 않는다.
