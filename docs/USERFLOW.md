# Userflow

## 전체 흐름

```text
메일 인증 → 프로필 → 혼자 신청 또는 방 만들기 → 친구 초대 → 빈자리 채우기
→ 상대 팀 매칭 → 전원 수락 → 방장 약속 입력 → 오픈채팅 공개
→ 현장에서 주도자 시작 → 단계별 활동과 미션 → 리워드 → 만남 후
```

## 1. 가입과 인증

1. `@inu.ac.kr` 메일을 입력한다. 다른 도메인은 프론트와 서버에서 모두 거부한다.
2. 서버가 6자리 코드를 실제 메일로 보낸다.
3. 코드를 입력하면 로그인된다.
4. 처음이면 학과, 학번, 성별을 입력한다. 학과와 학번을 넣기 전에는 다른 화면으로 갈 수 없다.

| 예외 | 처리 |
| --- | --- |
| 코드 틀림 | 5회까지 시도. 넘으면 새 코드 필요 |
| 코드 만료 | 10분 뒤 만료. 다시 보내기 |
| 메일 재전송 | 60초 간격 제한 |
| 메일이 안 옴 | 스팸함 안내와 다시 보내기 |

## 2. 신청

| 항목 | 내용 |
| --- | --- |
| 형식 | 1대1, 2대2, 3대3 |
| 모드 | 과팅 또는 친구 |
| 입력 | 가능한 시간, 관심사, 분위기, 불편한 주제 |
| 혼자 신청 | 1인 팀으로 등록하고 대기 |
| 방 만들기 | 초대 링크를 받아 친구를 부름. 빈자리는 혼자 신청자로 채울 수 있음 |

초대 링크는 로그인한 인증 사용자만 쓸 수 있고, 정원이 차면 막힌다.

## 3. 매칭

1. 코드가 팀의 빈자리를 채운다. 신청 묶음은 쪼개지 않는다.
2. 인원이 찬 두 팀을 묶는다. 다른 과 조합을 우선한다.
3. AI 주도자가 왜 이 조합인지 설명한다. 후보를 고르지는 않는다.
4. 참가자에게 메일을 보낸다. 앱의 "내 모임"에도 표시한다.

| 상태 | 뜻 |
| --- | --- |
| 대기 | 조합을 기다림 |
| 수락 대기 | 매칭됐고 전원의 수락을 기다림 |
| 약속 대기 | 전원이 수락했고 방장 입력을 기다림 |
| 약속 확정 | 날짜, 장소, 오픈채팅 링크가 있음 |
| 진행 중 | 주도자가 시작됨 |
| 완료 | 리워드까지 끝남 |

| 예외 | 처리 |
| --- | --- |
| 한 명이 거절 | 그 사람의 신청 묶음만 대기로 돌아감. 빈자리는 대기자로 채움 |
| 대기자가 없음 | 남은 사람은 수락 상태로 기다림 |
| 약속 후 나감 | 다른 참가자에게 메일 발송. 빈자리는 다시 채우지 않고, 방장이 남은 인원으로 진행하거나 모임을 취소 |

## 4. 방장과 약속

- 혼자 신청자로 만든 팀은 먼저 신청한 사람이 팀장이다.
- 매칭되면 먼저 만들어진 팀의 팀장이 모임 방장이다.
- 방장이 나가면 남은 수락자 중 먼저 신청한 사람이 이어받는다.
- 방장이 날짜, 장소, 오픈채팅 링크를 입력한다.
- 오픈채팅 링크는 전원이 수락한 뒤 참가자에게만 보인다.
- 방 화면에는 날짜, 장소, 어느 과, 몇 명, 누구누구를 표시한다. 전원 수락 전에는 이름과 학번을 숨기고 학과만 보인다.

## 5. 현장: AI 주도자

방장 폰 한 대로 진행한다. 다른 참가자는 방 화면에서 진행 상태를 볼 수 있다.

1. 방장이 단계 수(1~5, 기본 3)를 고르고 시작한다.
2. 주도자가 오프닝 멘트를 보여준다.
3. 각 단계는 활동 1개와 미션 사진 1개로 이루어진다.
4. 활동은 대화 주제, VS 게임, 짝 게임 중에서 고른다.
5. 뒤 단계로 갈수록 미션이 어려워진다.

| 예외 | 처리 |
| --- | --- |
| 불편한 대화 주제 | 바로 넘기면 다른 주제를 보여줌 |
| 성비가 안 맞음 | 짝을 랜덤으로 지음 |
| 사진 판정 실패 | 이유와 함께 재시도 |
| 직접 넘기기 | 방장이 언제든 다음 단계로 넘길 수 있음. 완주 뱃지는 받지 못함 |
| AI 활동 생성 실패 | 샘플 카드로 진행하고 샘플이라고 표시 |
| AI 판정 실패 | 직접 넘기기 또는 다시 시도 |

## 6. 미션 사진

1. 방장이 얼굴이 나오지 않는 사진이고 찍힌 참가자가 동의했음을 확인한다.
2. 사진을 찍어 올린다.
3. 서버가 위치 정보를 지우고 AI에게 판정을 요청한다.
4. 통과하거나 직접 넘긴 사진만 비공개 S3에 저장한다. 재시도 사진은 버린다.
5. 사진은 참가자만 볼 수 있고, 일주일 뒤 자동 삭제된다. 그 전에 참가자 누구나 삭제할 수 있다.

## 7. 리워드와 만남 후

| 결과 | 리워드 |
| --- | --- |
| 모든 단계를 AI가 통과 | 완주 뱃지와 추억 카드 |
| 직접 넘긴 단계가 있음 | 추억 카드 |

- 추억 카드는 사진과 AI 한 줄 후기를 묶은 화면이다. 모임당 1회 만들고, 참가자가 저장할 수 있다.
- 다시 만나고 싶은지 비공개로 고른다. 서로 원하면 양쪽에 메일을 보낸다.

## 8. 안전

- 방과 진행 화면에 신고와 나가기 버튼을 둔다. 신고는 DB에 저장하고, 운영자 처리는 대회 범위에서 뺀다.
- 공개 장소 안내와 음주 강요 금지 안내를 약속 화면에 보여준다.
- 활동과 미션은 술, 신체 접촉, 외모 평가를 다루지 않는다.
