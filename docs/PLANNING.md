# 나인팅게일 (가제) 기획

"확정"은 사용자가 결정한 내용, "제안"은 아직 확인이 필요한 내용이다.

## 한 줄 정의

혼자여도 신청할 수 있고, 만난 뒤의 어색함까지 AI 주도자가 풀어주는 인천대 과팅 웹.

차별점: 기존 앱은 만남 주선까지, 우리는 만난 후까지.

심사 메시지는 "AI 주도자" 하나로 모은다. 매칭 설명, 게임 진행, 사진 판정은 모두 주도자의 역할로 보여준다.

## 수익 모델 (발표용)

주변에서 소개팅을 잘 주도하는 친구가 주선자로 활동하고 주선 비용을 받는다. 오늘은 결제를 만들지 않고 발표에서 계획으로 설명한다. AI 주도자는 무료로 제공한다.

## 방장

- 방을 처음 만든 사람이 방장이다. 날짜, 장소, 오픈채팅 링크를 입력한다.
- 상대 팀과 매칭되면 방을 먼저 만든 쪽의 방장이 모임 방장이 된다.
- 오픈채팅 링크는 전원이 수락한 뒤에만 보인다.

## 매칭 규칙

- 신청 묶음은 쪼개지 않는다. 같은 형식과 시간대 안에서 팀의 빈자리를 혼자 신청자로 채운다.
- 인원이 찬 두 팀을 매칭한다. 다른 과 조합을 우선한다.
- 1대1은 혼자 신청자끼리만 매칭한다. 정확히 채워지지 않으면 대기한다.
- AI는 후보를 고르지 않고, 코드가 만든 조합의 이유만 설명한다.

## 만남 중 활동

활동은 모두 같은 형식의 카드다. 폰 한 대로 주도자 멘트를 읽고 다음으로 넘긴다.

### 대화와 VS

| 활동 | 예시 |
| --- | --- |
| 랜덤 대화 주제 | 깻잎 논쟁, 남사친 여사친은 있다 없다. 불편하면 바로 넘김 |
| VS 게임 | 짬뽕 vs 짜장, 매일 1교시 vs 공강 없는 시간표 |

### 짝 게임

짝은 남녀 1명씩 짓는다. 친구 모드와 성비가 안 맞는 모임은 랜덤으로 짓는다.

| 게임 | 방식 |
| --- | --- |
| 짝꿍 텔레파시 | 질문에 동시에 답하고, 같으면 1점 |
| 둘 진실 하나 거짓 | 내 이야기 3개 중 거짓을 짝이 맞힘 |
| 학과 용어 스피드 퀴즈 | 내 전공 용어를 설명해서 짝이 맞힘 |
| 초성 퀴즈 | 짝이 함께 제한 시간 안에 맞힘 |
| 5초 맞히기 | 타이머를 안 보고 5초에 가장 가깝게 멈춤 |
| 그림 릴레이 | 짝과 번갈아 그린 그림을 다른 짝이 맞힘 |

### 미션 사진

얼굴은 필요 없고, 신체 접촉과 술 관련 내용은 넣지 않는다. 방장이 1~5단계를 고르고 순서대로 진행한다. 뒤로 갈수록 어렵고, 단계별 미션은 랜덤이다. 시연은 3단계 중 2단계를 미리 완료해 두고 마지막 단계만 현장에서 수행한다.

| 종류 | 예시 |
| --- | --- |
| 협동 포즈 | 모두의 손으로 별 만들기, 손가락으로 INU 글자 만들기 |
| 물건 모으기 | 학과가 드러나는 물건 모으기, 가방 속 가장 웃긴 물건 모으기 |
| 짝 섞기 | 상대 팀과 그림 이어 그리기, 상대 팀 사람의 취미를 그림으로 그리기 |
| 찾기 | 주변에서 파란색 물건 5개 찾기, 메뉴판에서 가장 이상한 메뉴 찾기 |
| 창작 | 냅킨에 서로의 학과 마스코트 그리기, 젓가락으로 오늘 날짜 만들기 |
| 대화 결과 | 처음 알게 된 공통점 3개 적기, 최악의 공강 시간표 그리기 |
| 이야기 사진 | 사진첩에서 가장 웃긴 음식 사진을 다시 찍기, 신발만 모아 팀 이름 정하기 |
| 도전 | 모두의 그림자로 글자 만들기, 냅킨 탑 쌓기 |

### 사진 처리

- 판정: AI 주도자가 통과 또는 재시도와 짧은 근거를 준다. 틀리면 참가자가 직접 넘길 수 있다. 금전 보상의 단독 심판으로 쓰지 않는다.
- 보호: 업로드 전 방장 확인, 비공개 저장, 위치 정보(EXIF) 제거. 일주일 뒤 자동 삭제, 그 전에 참가자 누구나 삭제 가능.
- 리워드: 모임당 1회. 사진 판정은 금전 보상의 근거로 쓰지 않는다.
