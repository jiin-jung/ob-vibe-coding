# 프론트엔드 규칙

## 스택

Vite, React, TypeScript, CSS Modules. 정적 빌드만 쓰고 서버 렌더링은 쓰지 않는다.

## 규칙

- API는 항상 상대 경로 `/api`로 호출한다. 서버 주소를 코드에 넣지 않는다.
- 비밀 값을 프론트에 두지 않는다. S3와 Claude, 메일 호출은 백엔드에서만 한다.
- `@inu.ac.kr` 확인은 사용자 안내용이다. 실제 차단은 백엔드가 한다.
- 모바일 화면을 기준으로 만든다. 시연은 실제 폰으로 한다.
- 사진 촬영은 `<input type="file" capture>`를 쓴다.
- AI 샘플 응답은 화면에 샘플이라고 표시한다.

## 디자인

학사 포털과 성적표를 재치 있게 비튼 화면(제안). 인천대 로고는 쓰지 않는다. 가장 공들일 화면은 학년 이벤트와 현실 퀘스트, 성적표다.
